# agent-skill-ui-clean-architecture

A skill for building UIs using a framework-agnostic adaptation of Clean Architecture for the frontend world.

## Included

- `SKILL.md`: the operational manual for agents
- `knowledge/`: the source-of-truth architecture guidance
- `references/`: quick decision aids for reviewing and refactoring code

## Purpose

This repository defines how to keep business rules independent from UI details, external APIs, and platform-specific technologies while still delivering real user interfaces.
